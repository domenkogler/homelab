## Reading

* Cold prefill on this leg is ~880-1230 t/s, i.e. ~0.8-1.1 ms per prompt token, on a ~0.13-0.25 s
  floor. TTFT is therefore a linear function of how much the client sends, and the
  150-400 ms budget is met only below roughly 300-450 prompt tokens.
* A cached prefix answers in 0.10-0.17 s (repeat-cut800, repeat-gap, cold-cut1900). The cache did NOT
  answer for the 1 287/4 010/7 159-token repeats, so this run has no model for when it fires; a
  reading that relies on it is a reading that works on the demo and not on the afternoon.
* VERDICT: FAIL against the budget for any real-context tab prompt. The 444/454/521 ms figure in
  raw/40-coder-probes.txt was a ~40-token toy; this ladder is the same request shape at real sizes.
  The row's "sub-second is an assumption" is now a measurement, and the measurement is over budget.
* GPU state left as found: `lms unload --all`, `/v1/models` answers `{"data":[]}`,
  PDH dedicated back to 2.58 GiB (desktop floor).
