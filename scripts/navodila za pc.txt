 ### If You Want a Quicker Alternative

 Skip the script entirely. Open an elevated PowerShell and run:

 ```powershell
   # Install smartmontools if needed
   winget install smartmontools.smartmontools

   # Refresh PATH
   $env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" +
 [Environment]::GetEnvironmentVariable("Path","User")

   # Scan both NVMe drives
   smartctl -a /dev/nvme0 > $env:USERPROFILE\Desktop\smart-nvme0-970.txt
   smartctl -a /dev/nvme1 > $env:USERPROFILE\Desktop\smart-nvme1-960.txt
 ```
