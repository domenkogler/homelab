# secret_debt_register.txt — for every leak debt the ledger names: WHO can act, on WHICH seat, and
# whether the value behind it has ROTATED since the debt was recorded. The ledger
# (secret_leak_ledger.txt) is the mute-safe book of WHAT is exposed; this companion book is the
# register of WHAT STILL NEEDS AN ACT, which the ledger cannot state because `--update-ledger`
# rewrites its body and a fourth column here would die at the next run.
#
# One line per debt: <item-id-prefix><TAB><class><TAB><seat><TAB><vault-version-at-leak-time>
# <TAB><path><TAB><rotation-doc>. Never a value, a length, or a captured line — the same disclosure
# budget as the ledger and for the same reason (CONVENTIONS §6).
#
#   seat          `win11` | `wsl` | `oldsrv` — the seat whose capture store carries the hit. A line
#                 is judged by the seat that recorded it and by no other: a seat that read no store
#                 prints `NOT JUDGED` for a foreign line and may never close it. The book records all
#                 three seats, and it records them as separate reads, not as one fleet verdict: the
#                 same `(item, class)` pair carries one line per seat whose store holds the hit, and
#                 closing it there says nothing about it anywhere else. A seat the book carries no line
#                 for prints `NOT RECORDED` — a debt in a store no run read is unknown, never absent.
#   version       the item's vault `version` at the moment the debt was recorded. `version` is what
#                 turns "rotated?" from a memory into a fact: unchanged ⇒ provably NOT ROTATED,
#                 moved ⇒ CANDIDATE, and the content scan (`check_secret_leak.py`) is the proof.
#                 ⛔ No value is ever hashed for this: on credentials this short a hash is an offline
#                 guess-check, and a hash proves a holder, never a history.
#   path          `lane` (a lane reaches the far end: a host command, an app's config, a device API)
#                 | `lane+converge` (the same, and the propagation costs a converge)
#                 | `human` (no machine channel, or the write target is the HUMAN vault)
#                 | `none` (outside our scope — an ISP credential, a network account whose reset
#                 mail never arrives). The `none` set is the fleet's machine-readable statement of
#                 "nothing can rotate this", and it is held EQUAL to `NOT_ROTATABLE` in
#                 scripts/secrets/provision-secrets.py by check_secret_debt.py — two copies of one
#                 ruling is the twin every gate in this repo exists to catch. It is NOT the same set
#                 as `NOT_AUTO_ROTATABLE`, which is the auto-rotation ORDERING guard.
#   rotation-doc  the owning doc whose procedure closes the line, so the actor does not have to know
#                 where the far end is.
#
# Lines are added by hand when a re-derive mints a debt, and removed by hand when the checker prints
# `CLOSED — remove the line`. A line whose pair left the ledger WITHOUT a version move is the
# redaction-that-reads-as-a-rotation this book exists to refuse, and the checker reddens on it.
#
# A line does NOT need a ledger line to be written here. HD-1181 rules that a CURRENT value sitting in a
# capture gets no ledger line — a ledger line for a live value is the mute button that file's header
# forbids — so such a debt is honest and ledgerless at once, and the leak gate stays red on it. The
# checker prints those lines `UNLEDGERED` (red, and decided by reading the LEDGER AT HEAD rather than by
# guessing). Write the line when the debt is taken; delete it in the commit that rotates the value,
# which is the commit that makes `UNLEDGERED` move to `CLOSED`.
