# bench_provenance_exceptions.txt — off-station timed spark legs the repo has ACCEPTED, one line per leg.
# One line per leg: <step><TAB><ts><TAB><reason>. Those two keys ARE the leg's identity in the results
# CSV — `run-scenario.sh` writes one `step` + one immutable `RUN_TS` per leg — so a line excuses ONE leg
# that was already taken and cannot grow into an amnesty for a class. A line naming a host, a scenario, a
# profile arm or a model would retro-actively accept every leg of that shape, which is how a debt
# register becomes a mute button.
# The gate is scripts/gate/check_bench_provenance.py. A leg named here prints NAMED DEBT and the run
# stays green; an off-station leg that is not named here reddens it; a line whose leg is absent from the
# CSV read prints NOT MATCHED, so the book cannot quietly rot into a standing free pass — deleting a line
# is lawful only in the change that removes the leg it names.
# ONLY the station rule is excusable here. A leg stamped `agent:spark/…` — a timed number taken by a
# session served by the very engine it measures — is barred by Rule 0 (spark/llm-profiles/README.md) and
# no line in this file opens that door: an exception is a statement about a box, Rule 0 is a statement
# about a model. The station rule the exceptions are exceptions TO is docs/orchestration.md §4 and
# todo-table.md §C rule 9: the designated runner station is the WSL Debian laptop seat, off-box for every
# converge target, not the engine host, owner of no converge slot.
# A reason under 40 characters is refused by the gate, not warned: the line's whole job is the argument,
# so name the session that took the leg, why the station could not, and what the number may be quoted for.
# HD-1154: no line yet, and the case is decided rather than deferred. The gate reads ONE file —
# $RESULTS_CSV, else `<repo>/scripts/bench/spark/results-v2.csv` — and a leg's identity in it is the `step`
# + `ts` of one row, with the `client` column carrying the stamp the verdict is about; a file without that
# column is refused as NOT JUDGED (exit 2) rather than judged, because a run that could not read a leg's
# stamp does not get to call it clean. NO CSV ROW IS REACHABLE FROM THIS SEAT: the path above exists in no
# checkout, $RESULTS_CSV is unset, the only results CSV the tree carries is
# `scripts/bench/spark/raw/results.csv` and its header is the pre-v2 shape the gate refuses, and the
# pre-station legs the reports name (HD-489's `--client oldsrv`) are rows that live on the hosts, not in the
# tree. So the exception mechanism cannot pay HD-1154(a) as currently shaped. What would make a row
# readable is the file the gate names: a `results-v2.csv` written by `run-scenario.sh` — the writer's
# `client` stamp is the one column either rule can be judged from — sitting at
# `<repo>/scripts/bench/spark/results-v2.csv` or named in $RESULTS_CSV. Not a line here: a line for a row
# nobody can read books the amnesty without the debt.
