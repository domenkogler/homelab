# Frozen debt ledger for scripts/gate/check_doc_headings.py -- the dangling section pointers this
# repo has AGREED to carry, so the anchor half of a citation is a ratchet instead of a permanently
# red suite. Read that docstring before editing this file.
#
# One line per dangling pointer, four TAB-separated fields:
#     <count>TAB<path citing>TAB<target document>TAB<the pointer as written>
# Matched by KEY, never by line number: a pointer's position moves whenever a doc grows, and a
# ledger keyed on position would report an unrelated edit above it as new debt
# (gate/iac_identifier_allowlist.txt states the same rule for exemptions). `count` is how many
# copies of that one pointer dangle, so a repeated pointer cannot be cleared by deleting one line.
#
# Two directions fail, and both are the point:
#   GROWTH  a pointer this file does not carry, or carries fewer times than it appears.
#   STALE   a line here whose pointer now resolves. Clearing debt is a two-line change: fix the
#           pointer AND delete its line (or lower its count) in the same commit. A line that
#           outlives its pointer stops being agreed debt and becomes a free pass for the next
#           dangling pointer written at that key.
#
# Re-derive the body, never hand-edit it and never quote its counts (CONVENTIONS section 2):
#     python3 scripts/gate/check_doc_headings.py --show-baseline > /tmp/headings-baseline.txt
# then replace the lines below this header with that file -- stdout is the body only, so the
# header is never what the redirect overwrites, and the command's own summary goes to stderr.
# Nothing here is a decision log: an entry's existence says the debt is carried, and the reason a
# given pointer is not worth fixing yet belongs in the doc that owns the section.
