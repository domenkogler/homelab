# T0 — Validator script `scripts/validate-docker-services.py` (baseline: 8 missing)

**Objective:** Create a pure-Python validator that renders every
`docker_services` compose template from `group_vars/home_servers.yml` with a
mock 1Password lookup, checks conventions, and exits 0 only when all 27
entries' templates (19 existing + 8 new) are valid. Baseline result now:
reports the 8 missing template dirs and exits 1.

**File scope (ONLY these):**
- `scripts/validate-docker-services.py` (new)

**Exact design to implement (transcribe to the script):**
- Pure stdlib + `yaml` + `jinja2` (both installed). No network, no docker, no ansible.
- Read `IaC/ansible/group_vars/home_servers.yml` with `yaml.safe_load`, take
  `docker_services` (a list of dicts with keys: name, template_dir, optionally
  subdomain/instance/enabled).
- For each entry: assert `<template_dir>/docker-compose.yml.j2` exists under
  `IaC/ansible/templates/docker_services/`.
- Render with `jinja2.Environment(undefined=StrictUndefined, keep_trailing_newline=True, trim_blocks=True, lstrip_blocks=True)`.
- **Mock `lookup`:** add a Jinja global/function `lookup('community.general.onepassword', name, vault=...)` → returns `"<secret:" + str(name) + ">"`. (Ansible exposes it as `lookup(plugin, *args, **kwargs)` inside expressions.)
- **Mock `comment` filter:** `# `-prefixed lines (same as `scripts/validate_doc_templates.py`).
- **Render context** (any var missing from a template now fails via StrictUndefined — that is the anti-drift guard):
  `timezone=Europe/Ljubljana`, `op_vault=Homelab`, `domain_public=kogler.si`, `domain_local=kogler.si`, `letsencrypt_email=domen@kogler.si`, `traefik_version=latest`, `certs_dumper_version=v2.8.3`, `wildcard_cert_file=kogler.si.pem`, `wildcard_cert_key_file=kogler.si-key.pem`, `wildcard_cert_domain=kogler.si`, `technitium_secondary_ip=10.10.1.20`, `ha_vip=10.10.1.200`, `ha_vip_cidr=24`, plus per-entry extras from the dict (`subdomain`, `instance`, `enabled`, `homelab_mode=desktop`, `gpu_vendor=amd`, `ollama_keep_alive=5m`, `gpu_render_gid=123`, `gpu_video_gid=124`, `ansible_user=ansible-admin`, `inventory_hostname=oldsrv.kogler.si`).
- Parse rendered text with `yaml.safe_load` (must be a dict with `services:` non-empty).
- Per-service rule set (keyed by `name`, applied only to the 8 new services + generically to all):
  - every service defines `image`, `restart`; restart ∈ {always, unless-stopped, "no"}
  - networks of each service ⊆ the allowed sets:
    - homepage: {traefik-public}
    - renovate, blackbox-exporter, signal-cli-rest-api: {services-internal}
    - prometheus, loki: {db-internal}
    - doco-cd: {host network style — uses `network_mode: host` and mounts docker.sock}
    - metabase: {traefik-public, services-internal}
    - existing services: no constraint beyond "networks defined" (avoid breaking current templates)
  - web services REQUIRE Traefik labels (`traefik.enable: "true"`, router rule, `tls.certresolver: letsencrypt`, `entrypoints: websecure`, and the `authentik-forward-auth@file` middleware) — applied to: homepage (rules `Host(\`kogler.si\`)` **and** `Host(\`home.kogler.si\`)`), metabase (rule `Host(\`sec.kogler.si\`)`)
  - non-web services (renovate, doco-cd, prometheus, loki, blackbox-exporter, signal-cli-rest-api) must NOT set `traefik.enable: "true"` (absent or false)
  - secret-hygiene: any env/volumes key whose lowercase name contains `password`, `secret`, `token`, or `key` must have a value containing `lookup(` (no literals)
- `--only <name>` CLI arg: validate just that entry (used by T1–T8).
- Exit 0 and print `PASS: <n> docker_services templates valid` when everything passes;
  otherwise print each violation (`[service] <message>`) and exit 1.
- Baseline today: run WITHOUT any fixes must print the 8 missing-template dirs and exit 1.
