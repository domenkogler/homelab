**Design decisions (from the SSOT — encode these, do not invent others):**
- Prometheus is the **only metrics store**. It does NOT scrape host/SNMP metrics —
  the Alloy host agent **remote-writes** them (observability.md architecture).
- Scrape targets Prometheus itself needs:
  1. `blackbox-exporter` (service name on `services-internal`, port 9115, `metrics_path: /probe`) — HTTP probes (`module: http_2xx`) for `https://kogler.si`, `https://sso.kogler.si`, `https://foto.kogler.si`, `https://file.kogler.si`, `https://git.kogler.si`, `https://ha.kogler.si`; ICMP probes (`module: icmp`) for router `10.10.99.1` + switch `10.10.99.2`. Use the standard blackbox relabelings (`__address__`, `__param_target`, `instance`, `__param_module`).
  2. `nut_exporter` — **host binary on nas**, scrape `10.10.1.10:9195` (Home VLAN; container→LAN egress via Docker NAT is accepted).
  3. HA exporter — HA's native `/api/prometheus` behind the edge: target `http://{{ ha_vip }}:8123`, `metrics_path: /api/prometheus`, `bearer_token: {{ lookup('community.general.onepassword', 'ha_exporter_token', vault=op_vault) }}`.
  4. Service self-metrics: `traefik` (`http://traefik:8082/metrics`), `crowdsec` (`http://crowdsec:6060/metrics`), `doco-cd` (`http://doco-cd:<port>/metrics` — port from T7; if T7 has not run yet, write the job with a var `doco_cd_metrics_port | default(8008)` so the template still renders; T7 may adjust the default).
- No Prometheus alert rules: alerting lives in Grafana Alerting (observability.md).
- Retention 30d via `--storage.tsdb.retention.time=30d`; data volume `prometheus-data`.

**Exact compose template content:**
```
# prometheus docker-compose.yml — SOLE metrics store (30d retention, db-internal)
#   Receives remote_write from Alloy (host/SNMP); scrapes blackbox, nut_exporter,
#   HA exporter and service /metrics. Grafana queries Prometheus on db-internal.
#   TSDB is regenerable and NOT backed up (docs/backup.md).
#   See docs/observability.md. Secrets via
#   {{ lookup('community.general.onepassword', '<name>', vault=op_vault) }}
services:
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    restart: unless-stopped
    command:
      - "--config.file=/etc/prometheus/prometheus.yml"
      - "--storage.tsdb.path=/prometheus"
      - "--storage.tsdb.retention.time=30d"
    networks:
      - db-internal
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - prometheus-data:/prometheus
volumes:
  prometheus-data:
networks:
  db-internal:
    external: true
```
